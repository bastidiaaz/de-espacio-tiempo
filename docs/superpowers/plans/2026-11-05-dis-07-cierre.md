# Cierre del Acto I (DIS-07) — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** implementar la secuencia de cierre del Acto I: capítulo nuevo de la fogata, Isi sentada, la estrella mirada sentada, la cámara guiada mientras entra el coro (el coro en sí llega con AUD-01) y, cuando la cámara vuelve a la estrella, la pantalla final «Te sientas junto al fuego» con la invitación a ffm.to.

**Architecture:** la lógica nueva vive en módulos puros testeables en Node (`systems/seat.ts`, `story/closing.ts`, `story/saveMigration.ts`). `Game.ts` solo los orquesta y publica estado serializable al store. La UI lee `seated`, `fade` y `endingVisible`; el texto sale de `acto1.json`.

**Tech Stack:** TypeScript, Three.js 0.160.0, React, zustand v5, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-03-de-espacio-tiempo-acto1-astronauta-design.md`, sección "Cierre (DIS-07)" (y la tabla de objetos). Léelo antes de empezar.

## Global Constraints

- Reglas de `CLAUDE.md`: `src/game/**` no importa React; `src/ui/**` no importa `three`; el store solo recibe valores serializables y solo cuando cambian.
- No cambiar claves de `localStorage` (`lvr-mem-<seed>`, `lvr-acts-done`, …) ni el orden de llamadas a `rng()` en `storyWorld.ts`/`chunks.ts`/`sky.ts`. `terrain.test.ts` debe seguir pasando sin regenerar fixtures.
- El cielo no amanece: `PRE_DAWN = 0.12` sigue siendo el tope.
- Textos in-game: los escribe el autor. Los únicos textos nuevos que van tal cual son los suyos: «Tengo mucho en mi cabeza. Necesito sentarme a reordenar mis ideas...» y «Te sientas junto al fuego». Todo lo demás que falte va como marcador con el prefijo exacto `[PENDIENTE] ` (el autor lo reemplaza).
- URL de la invitación: `https://ffm.to/tiann-astronauta`, en una pestaña nueva (`target="_blank" rel="noopener"`).
- Numeración: capítulos 0–5 en código (`chapter`); claves del JSON = índice + 1 (`capitulo5` = fogata, `capitulo6` = estrella).
- *Reduced motion* (`prefersReducedMotion`): sentarse/levantarse es un fundido corto sin movimiento de cámara; durante el coro la cámara no se mueve (queda en la estrella).
- Cada tarea termina con `npm run lint && npm run typecheck && npm test && npm run build` en verde y un commit. Se publica por partes: cada tarea deja el juego jugable.

## Review Focus

1. **Recargar a mitad del cierre** (durante las 4 frases, el coro o la espera): debe volver sentada al cap. 5 y poder mirar la estrella otra vez; nunca quedar en paseo libre sin haber visto la pantalla final. → test en Task 1 (migración) + verificación manual en Task 3.
2. **Partida guardada antigua terminada** (`star` presente, sin `campfire`): debe cargar como terminada (paseo libre, intro "completo"), no en el cap. 4. → test en Task 1.
3. **Táctil sentada:** tocar la mitad izquierda no debe sacar el joystick ni mover a Isi; debe servir para mirar. → test en Task 2 (`input.test.ts`).
4. **Opciones/pausa durante la cámara guiada:** pausar congela la cuenta del cierre; al reanudar sigue desde donde estaba (el temporizador no corre con `setTimeout` sino con `dt` del loop). → test en Task 3 (`closing.test.ts`, `update` no avanza si no se llama).
5. **Saltos de debug en medio del cierre:** `debugJumpToChapter`/`debugJumpToItem` deben cancelar el cierre y dejar la postura correcta (de pie en caps. 0–4, sentada en el 5). → verificación manual en Task 3 con `#debug`.

  export const CLOSING = { leadIn: 1.5, camera: 18, holdBeforeEnding: 1 } as const;
  export type ClosingStage = 'idle' | 'leadIn' | 'camera' | 'hold' | 'ending';
  export interface Look { yaw: number; pitch: number }
  export class Closing {
    stage: ClosingStage;              // inicia 'idle'
    start(): void;                    // 'idle' → 'leadIn'
    reset(): void;                    // → 'idle'
    /** Avanza el reloj; devuelve la etapa nueva solo el frame en que cambia, si no null. */

    get cameraU(): number;
    get locksLook(): boolean;         // true en 'camera', 'hold' y 'ending'

  /** u 0..1 (18 s): 0–5/18 baja de la estrella al fuego (easeInOut), hasta 12/18 queda en el fuego, 12/18–1 sube a la estrella. Yaw con interpolación angular. */
